# Jan Sahayak - Login + Activity

## Run
1. Open VS Code in this project.
2. Open terminal:
   cd backend
   npm install
   npm start
3. Open http://localhost:5000

## Added
- Login page shown first
- Register new users
- Passwords stored as hashes using Node.js crypto
- Login/logout activity tracking
- Registered user counter
- Login, logout and registration counters
- Recent activity list
- Existing welfare scheme search preserved

Data is stored locally in:
backend/data/users.json
backend/data/activity.json
